Modul 5: Varian Linked List

Menguasai Doubly Linked List (penelusuran bolak-balik & hapus ujung $O(1)$) dan Circular Linked List (rantai melingkar berujung tunggal), memverifikasi dua invarian utama, serta membongkar bug diam via detektor utuh().

01. Dua Arah
Bebas maju-mundur via pointer prev dan next. Hapus ekor seketika $O(1)$.
02. Dua Invarian
Relasi dua arah p->next->prev == p. Menangkap kesalahan pointer tepat di lokasi penyebabnya via utuh().
03. Circular Ring
Cukup pegang tail, otomatis kuasai kepala & ekor. Wajib loop do-while!
04. Overhead 24 Byte
83% memori dipakai untuk pointer dan padding. Pahami kapan linked list tepat digunakan.

The Big Question • Refleksi Modul 4

"Pekan Lalu Singly Linked List Sudah Keren, Apa yang Kurang?"

Dua kelemahan menyakitkan dari Singly Linked List yang memicu lahirnya Doubly & Circular:

🙈

1. Keterbatasan Penelusuran Satu Arah

Pada Singly Linked List, tiap node cuma punya pointer next. Kamu cuma bisa maju, tidak bisa mundur! Ingin mencetak list dari belakang? Mustahil tanpa menyalin seluruh list atau rekursi yang boros stack. Ingin menyisipkan sebelum suatu node? Harus mulai jalan kaki dari head lagi!

🐢

2. Hapus Akhir Tetap Lambat O(N) Walaupun Punya Tail!

Ini fakta mengejutkan: di Singly, memasang pointer tail cuma mempercepat tambah akhir, tapi tidak menolong penghapusan akhir sama sekali! Kenapa? Karena saat tail dihapus, pointer tail harus mundur ke node $N-2$, padahal Singly tidak punya jalan mundur. Kamu tetap harus menelusuri $N$ langkah dari head!

💡 Solusi Modul 5: Tambahkan pointer prev $ o$ jadilah Doubly Linked List. Sambungkan ujung ekor kembali ke kepala $ o$ jadilah Circular Linked List!
Dasar Teori 5.2.1 • Struktur Fisik

Anatomi Doubly Linked List & Overhead 24 Byte

Dua pointer per gerbong: prev ke pendahulu, next ke penerus.

doubly_node.cpp sizeof = 24 Byte 
struct node_t {
    node_t *prev;  // 8 byte (alamat node sebelumnya)
    int info;      // 4 byte (muatan data)
    node_t *next;  // 8 byte (alamat node sesudahnya)
    // + 4 byte padding alignment 64-bit = 24 Byte!
};

struct list_t {
    node_t *head;  // node pertama atau nullptr
    node_t *tail;  // node terakhir atau nullptr
    int nef;       // banyaknya node yang hidup
};
🎯 Tail Bukan Hiasan: Berkat pointer prev, saat menghapus tail kita bisa langsung mundur ke tail->prev dalam 1 langkah! Hapus akhir resmi menjadi O(1).
⚖️

Analisis Kebutuhan Memori (Memory Overhead) 64-bit:

Perhatikan perbandingan menyimpan 1 juta bilangan bulat (int = 4 byte):

Array Statis (1 jt int): 3.8 MiB
Singly Linked List (16B / node): 15.3 MiB
Doubly Linked List (24B / node): 22.9 MiB (6x lipat array!)
Fakta Nyata: Pada doubly linked list berisi int, 83% memorinya habis hanya untuk pointer dan padding, bukan untuk datanya! Ini alasan kita harus cerdas memilih struktur data sesuai kebutuhan.
Konsep Kunci • 5.2.1.2

Dua Invarian pada Doubly Linked List

Doubly linked list memiliki dua pernyataan logika matematika yang wajib selalu bernilai benar setiap saat:

Invarian 1 (Maju lalu Mundur) p → next → prev
p->next->prev == p

Berlaku untuk setiap node p yang memiliki next. Jika kamu melangkah maju ke tetangga kanan, lalu menoleh ke kiri, kamu wajib kembali menatap dirimu sendiri!

Invarian 2 (Mundur lalu Maju) p → prev → next
p->prev->next == p

Berlaku untuk setiap node p yang memiliki prev. Jika kamu melangkah mundur ke tetangga kiri, lalu menoleh ke kanan, kamu wajib kembali menatap dirimu sendiri!

Syarat Batas di Ujung List:
head->prev == nullptr dan tail->next == nullptr

Fungsi Pemeriksa: bool utuh(const list_t &L)

Rantai yang putus tidak menimbulkan pesan kesalahan. Program tetap jalan lalu crash 200 baris kemudian. Fungsi ini mendeteksi kesalahan pointer secara langsung pada operasi yang merusaknya, bukan saat program sudah berjalan jauh.

Cara Kerja Fungsi utuh():

  1. Periksa apakah head->prev ada isinya? Jika ada $ o$ palsu / rusak!
  2. Periksa apakah tail->next ada isinya? Jika ada $ o$ rusak!
  3. Jelajahi seluruh node: periksa apakah p->next->prev == p dan p->prev->next == p.
  4. Jika ada 1 saja jabat tangan yang putus sepihak $ o$ langsung return false!
Saran Pengerjaan: Panggil utuh(L) setelah setiap operasi yang mengubah pointer. Bila fungsi mengembalikan false, operasi tersebut yang perlu diperbaiki.
utuh.cpp (Solusi TODO 1) LULUS 
bool utuh(const list_t &L) {
    // 1. Syarat batas kedua ujung
    if (L.head && L.head->prev != nullptr) return false;
    if (L.tail && L.tail->next != nullptr) return false;

    // 2. Uji cermin dua arah di seluruh node
    for (node_t *p = L.head; p != nullptr; p = p->next) {
        if (p->next && p->next->prev != p) return false;
        if (p->prev && p->prev->next != p) return false;
    }
    return true;
}
Dasar Teori 5.2.2.1 • Pengujian Termurah

Penelusuran Dua Arah: CetakMaju & CetakMundur

Pengujian paling murah sedunia: Cetak maju dari head, cetak mundur dari tail. Apakah yang satu kebalikan persis dari yang lain?

traversal_dua_arah.cpp Simetris 
// Dari DEPAN ke BELAKANG (mulai head, ikuti next)
void CetakMaju(const list_t &L) {
    for (node_t *p = L.head; p; p = p->next)
        cout << p->info << ' ';
}

// Dari BELAKANG ke DEPAN (mulai tail, ikuti prev)
void CetakMundur(const list_t &L) {
    for (node_t *p = L.tail; p; p = p->prev)
        cout << p->info << ' ';
}

Contoh Output Rantai Valid:

maju : 7 10 4 13 head → tail
mundur : 13 4 10 7 tail → head
utuh(L) = true nef = 4

Jika kamu mencetak mundur tapi hasilnya berhenti di tengah atau menghasilkan urutan angka yang aneh, artinya pointer prev salah satu node lupa disambungkan!

InsertLast: Tambah Akhir & Batas List Kosong

Menyisipkan elemen di akhir list. Karena kita memegang tail, biayanya instan 0 node dilewati: O(1)!

Dua Skenario InsertLast:

1. List Masih Kosong (L.tail == nullptr):

Node baru adalah satu-satunya elemen, maka head JUGA wajib menunjuk node baru (L.head = baru;).

2. List Sudah Punya Elemen:

Sambungkan ekor lama ke node baru: L.tail->next = baru;.

Terakhir, pindahkan tail ke node baru: L.tail = baru; L.nef++;

InsertLast.cpp (Solusi TODO 2) Biaya: O(1) 
void InsertLast(list_t &L, int x) {
    node_t *baru = new node_t;
    baru->info = x;
    baru->next = nullptr;
    baru->prev = L.tail; // Menghadap ke ekor lama

    if (L.tail == nullptr) {
        L.head = baru;   // List kosong: head ikut diisi!
    } else {
        L.tail->next = baru; // Sambung maju
    }

    L.tail = baru;       // Pindahkan ekor
    L.nef++;
}

InsertAfter: Urutan 4 Penugasan Pointer

Menyisipkan node baru tepat sesudah node q. Urutan 4 penugasan ini harus dijalankan sesuai urutannya agar tidak kehilangan alamat node.

Urutan Wajib 4 Penugasan:

1. baru->prev = q;
2. baru->next = q->next;
3. if (q->next) q->next->prev = baru; else L.tail = baru;
4. q->next = baru; // WAJIB PALING TERAKHIR!
Dampak Jika q->next Diubah Terlalu Awal: Alamat penerus lama tertimpa. Langkah berikutnya akan menghasilkan baru->next = baru (node menunjuk ke dirinya sendiri), dan sisa rantai di sebelah kanan terputus.
InsertAfter.cpp (Solusi TODO 3) 4 Assignment 
void InsertAfter(list_t &L, node_t *q, int x) {
    if (!q) return;
    node_t *baru = new node_t;
    baru->info = x;

    baru->prev = q;         // 1. Sambung kiri baru
    baru->next = q->next;   // 2. Sambung kanan baru

    if (q->next != nullptr) {
        q->next->prev = baru; // 3a. Tetangga kanan balik menunjuk baru
    } else {
        L.tail = baru;        // 3b. q adalah tail, pindahkan tail!
    }

    q->next = baru;         // 4. TERAKHIR: q menunjuk baru
    L.nef++;
}
TODO 4 Praktikum • 5.2.2.5

InsertBefore: Menyisipkan Sebelum Node & Batas Head

Menyisipkan node baru tepat di depan node q. Pada singly ini butuh jalan kaki dari depan, di doubly ini O(1) langsung!

Cermin dari InsertAfter:

Logikanya sama persis dengan InsertAfter, hanya arahnya yang terbalik:

  • • Node baru menunjuk q sebagai next, dan q->prev sebagai prev.
  • • Batas Head: Jika q == L.head (artinya q->prev == nullptr), maka node baru resmi menjadi kepala baru: L.head = baru;!
  • • Jangan lupa: q->prev = baru;.
✔ Periksa Invarian: Begitu selesai, L.head->prev harus tetap nullptr dan utuh(L) wajib mengembalikan true.
InsertBefore.cpp (Solusi TODO 4) Batas: q == head 
void InsertBefore(list_t &L, node_t *q, int x) {
    if (!q) return;
    node_t *baru = new node_t;
    baru->info = x;

    baru->next = q;         // 1. Sambung kanan ke q
    baru->prev = q->prev;   // 2. Sambung kiri ke pendahulu q

    if (q->prev != nullptr) {
        q->prev->next = baru; // 3a. Pendahulu menunjuk baru
    } else {
        L.head = baru;        // 3b. q adalah head! Pindahkan head
    }

    q->prev = baru;         // 4. q menunjuk baru ke kiri
    L.nef++;
}

DeleteNode: Hapus Node yang Alamatnya Dipegang (O(1))

Jika alamat node q sudah kita pegang, kita bisa menghapusnya seketika tanpa mencari dan tanpa menelusuri list sama sekali!

4 Kasus Batas yang Wajib Ditangani:

1. q di Tengah: Tetangga kiri lompat ke tetangga kanan, dan sebaliknya.
2. q adalah Head (q->prev == nullptr): Pindahkan L.head = q->next.
3. q adalah Tail (q->next == nullptr): Pindahkan L.tail = q->prev.
4. List Berisi 1 Node (q adalah head sekaligus tail): Kedua pointer head & tail menjadi nullptr sempurna!
DeleteNode.cpp (Solusi TODO 5) 0 Node Dilewati 
void DeleteNode(list_t &L, node_t *q) {
    if (!q) return;

    // Sambung pintas sisi kiri
    if (q->prev != nullptr) {
        q->prev->next = q->next;
    } else {
        L.head = q->next; // q adalah head
    }

    // Sambung pintas sisi kanan
    if (q->next != nullptr) {
        q->next->prev = q->prev;
    } else {
        L.tail = q->prev; // q adalah tail
    }

    delete q; // Kembalikan 24 byte ke heap
    L.nef--;
}

Circular Linked List: Mengapa Cuma Pegang Tail, Bukan Head?

Pada circular linked list, pointer next milik node terakhir menunjuk kembali ke node pertama!

🔄

Alasan Memegang Tail daripada Head:

Pada list melingkar:

  • ✔ Dari tail, kita bisa menemukan head dalam 1 langkah: head = tail->next;!
  • ✖ Sebaliknya, jika kamu cuma memegang head, untuk mencari tail kamu harus berputar mengelilingi $N$ node!
💡 Kesimpulan Elegan: Dengan hanya menyimpan satu variabel pointer saja (tail) di dalam clist_t, kita otomatis menguasai kedua ujung (awal dan akhir) secara bersamaan!
circular_singly.cpp Ringkas & Hemat 
// Node tetap sederhana (seperti singly modul 4)
struct cnode_t {
    int info;
    cnode_t *next;
};

// List HANYA memegang TAIL!
struct clist_t {
    cnode_t *tail; // head = tail->next
    int nef;
};

void CBuat(clist_t &C) {
    C.tail = nullptr;
    C.nef = 0;
}

Penelusuran Circular: Kenapa Wajib do-while?

Mencetak seluruh elemen list melingkar dari kepala sampai ekor. Mengapa while biasa gagal total?

Jebakan Maut Perulangan Melingkar:

Jika kamu memulai dari p = head lalu menulis:

while (p != head) { cout << p->info; p = p->next; }

Kondisi p != head langsung FALSE di langkah pertama! Perulangan langsung bubar tanpa mencetak satu pun angka.

Dengan do { ... } while (p != head);, badan perulangan dijamin berjalan minimal 1 kali dulu sebelum memeriksa apakah sudah kembali ke kepala!

⚠️ Batas List Kosong: Jika list kosong (tail == nullptr), tail->next akan crash instan! Wajib ada penjaga: if (!C.tail) { cout << "(kosong)"; return; }.
CCetak.cpp (Solusi TODO 8) do-while 
void CCetak(const clist_t &C) {
    // 1. Tangani list kosong terlebih dahulu!
    if (C.tail == nullptr) {
        cout << "(kosong)";
        return;
    }

    // 2. Mulai dari head (tetangga kanan tail)
    cnode_t *head = C.tail->next;
    cnode_t *p = head;

    // 3. Cetak dulu, baru uji apakah sudah 1 putaran
    do {
        cout << p->info << " ";
        p = p->next;
    } while (p != head);
}

CInsertLast & Cara Kerja CDeallocate

Menambah elemen di list melingkar dan cara membebaskan memorinya tanpa terjebak infinite loop.

CInsertLast (TODO 7)

O(1)

List kosong: node baru menunjuk dirinya sendiri (baru->next = baru;). Jika sudah ada elemen: node baru disisipkan di antara tail dan head! 

void CInsertLast(clist_t &C, int x) {
    cnode_t *baru = new cnode_t;
    baru->info = x;
    if (C.tail == nullptr) {
        baru->next = baru; // Menunjuk dirinya
        C.tail = baru;
    } else {
        baru->next = C.tail->next; // Sambung ke head
        C.tail->next = baru;
        C.tail = baru;
    }
    C.nef++;
}

CDeallocate (TODO 9)

Putus Dulu!

Pada lingkaran, while (p != nullptr) berputar selamanya! Wajib putuskan lingkarannya dulu: jadikan C.tail->next = nullptr;! 

void CDeallocate(clist_t &C) {
    if (C.tail == nullptr) return;
    cnode_t *head = C.tail->next;
    C.tail->next = nullptr; // 1. PUTUS LINGKARAN!
    cnode_t *p = head;
    while (p != nullptr) {
        cnode_t *berikut = p->next;
        delete p;
        p = berikut;
    }
    C.tail = nullptr; C.nef = 0;
}
